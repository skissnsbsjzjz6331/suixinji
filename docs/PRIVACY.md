# 随心记隐私说明（1.0.0）

随心记无需注册或登录。应用没有自建服务器、广告 SDK、分析 SDK，也不会自动上传账单。

## 数据保存位置

- 账单、预算与主题设置保存在当前手机安装实例的 WebView 本地存储中。
- Android 已关闭应用数据自动备份。iOS 是否纳入设备级备份取决于用户的系统设置；应用本身不提供云同步。
- 标准 Android 版、华为版、iOS 版和浏览器预览各自使用独立的本地存储，不会自动互通。
- 原生图标字体和界面资源随安装包提供，日常记账不需要网络连接。

## 文件导入与导出

用户主动选择的账单文件在本机解析。导出 CSV 时，应用生成本地临时文件并调用系统分享菜单；只有用户自行选择云盘、聊天软件等目标时，数据才会交给该目标应用。导入或导出前请核对文件内容。

## 版本更新

从 1.0.2 起，应用会向本项目的 GitHub 公共发布列表查询版本号和更新说明。请求不包含账单、主题、预算或登录凭据。选择「前往下载」会打开 GitHub 发布页。

## 删除与备份

应用内可删除单条记录，或经确认清空所有账单及设置。卸载应用或清除应用数据也会移除本地账本。当前版本没有自动恢复服务，请在换机、卸载或清理数据前主动导出 CSV。

## 联系与问题反馈

可在本项目的 GitHub Issues 中反馈问题。请勿在公开 Issue 中附上真实账单、账号或其他敏感信息。
